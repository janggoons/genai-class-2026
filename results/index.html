두 번의 특강에서 학생들이 모둠 활동판에 남긴 기록을 정리했습니다. 1차에는 AI가 틀리는 상황을 직접 만들었고, 2차에는 공부하면서 불편했던 점을 출발점으로 Gemini 캔버스에서 공부 앱을 만들었습니다. 2인 1모둠, 8모둠이 아이패드로 참여했습니다.

2차: 학생들이 만든 공부 앱 8개

모둠마다 공부하며 불편했던 점을 적고, 기능과 테스트 3개를 먼저 정한 뒤 만들기 시작했습니다. 만드는 동안에는 요청하고, 실행하고, 확인하고, 수정하는 과정을 반복하며 AI가 틀린 순간을 기록했습니다.

모둠 A

모기 (모의고사 지문 분석기)

출발한 불편 모의고사 오답에서 같은 내용을 자꾸 틀립니다. 영어 시험 범위가 넓어 내용을 기억하기 힘듭니다.

기능 지문 도식화, 지문 내용 퀴즈, 시험에 나올 문법 요소를 형광펜으로 표시

틀린 퀴즈는 변형해서 다시한 문장씩 해석

AI가 틀린 순간 수정을 요청하면 그 전에 고친 내용이 사라졌습니다. 되돌려 달라는 요청도 통하지 않아 처음부터 다시 만들었습니다. 변형 문제가 한 번만 나오거나 다음 문제로 넘어가지 않는 문제도 하나씩 고쳤습니다.

"형광펜으로 중요한 부분을 표시해서 보기 편함", "등록한 문제를 다른 형태로 바꿔 풀 수 있는 기능이 좋았다" · 제안: 글자를 더 크게

모둠 B

클락

출발한 불편 공부하다 모르는 단어나 내용이 나오면 하나하나 찾아보느라 시간이 걸립니다.

기능 개념 설명, 예문과 관련 기출, 유의어와 반의어, 1일·1주·2주·1달 뒤 복습

힌트는 키워드부터 한 단계씩

AI가 틀린 순간 문제를 풀어 달라고 하자 앱이 오히려 사용자에게 풀이를 요구했습니다. 앱이 직접 찾아서 알려 주도록 고쳤고, 그 뒤로는 앱이 문제를 풀었습니다.

"모든 과목의 개념을 공부할 수 있고, 카메라로 필요한 부분을 직접 등록할 수 있어 편리하다. 카드도 섞을 수 있다."

모둠 C

Øpick! (오픽)

출발한 불편 틀린 문제를 다시 풀어 보고 확인하기가 번거롭습니다.

기능 문제집을 찍으면 문제·보기·해설을 잘라 입력, 오답 원인 태그(계산 실수, 개념 미숙, 문제 오독), 자주 틀리는 유형 통계

틀린 것을 다시 본다먼저 떠올린다단계별 힌트

AI가 틀린 순간 객관식 답을 고를 수 없어 고쳤더니 다른 곳이 망가져 한 번 더 고쳤습니다. 수식이 어색하게 나와 수능 스타일로 바꿨지만 일부만 해결됐습니다. 오답 제목에 수식이 깨져서 범위·종류·번호로 표시하게 했습니다. 단계별 힌트는 끝까지 구현되지 않았습니다.

"오답을 하였을 때 틀린 것을 바로 복습하게 해 주는 것이 정말 좋았어요." · 제안: 예시 문제가 더 많았으면

모둠 D

클딱 (영단어 사전)

출발한 불편 영어 공부 중 모르는 단어를 휴대폰으로 찾느라 시간이 걸립니다.

기능 카메라 즉시 번역, 원터치로 저장하는 '1초 단어장', 검색한 단어의 분류와 맞춤 복습

모르면 모른다고 대답한다

테스트 테스트 가운데 하나가 "앱에 저장되어 있지 않은 단어가 나오면 확실히 모른다고 말해야 한다"였습니다. 1차에서 본 '지어낸다'를 앱의 테스트로 옮긴 것입니다.

AI가 틀린 순간 정해 준 앱 이름 대신 "영단어사전"이라는 이름을 붙였습니다. 아이콘 수정 요청은 한 번에 반영되지 않았습니다. 단어를 미리 넣어 두도록 바꾸자 일부 단어만 바로 나오고 나머지는 '등록 요청'이 떴습니다.

모둠 E

Matter matterS

출발한 불편 AI가 18족 원소의 원자가 전자 수를 틀리게 설명해 선생님께 다시 여쭤봤습니다. 사회 서술형 문제를 부탁했더니 범위 밖 내용과 처음 보는 사상가가 나왔습니다.

기능 개념과 설명을 직접 입력, 설명의 일부를 보여 주고 개념을 쓰게 하는 문제, 30초 제한

먼저 떠올린다틀린 것을 다시 본다

AI가 틀린 순간 개념 삭제 버튼이 작동하지 않았습니다. 같은 요청을 두 번 해도 그대로였는데, 방식을 바꿔 "한 번 더 묻고 삭제"하도록 요청하자 해결됐습니다. 퀴즈 중단과 전체 삭제도 같은 방식으로 고쳤습니다.

"개념 관리와 퀴즈 풀이를 같이 하면서 사탐 개념을 배우기 좋을 것 같아요." · 제안: 과탐도

모둠 F

풀림

출발한 불편 틀린 문제와 비슷한 변형 문제를 풀어 보고 싶습니다.

기능 틀린 문제를 찍으면 형식이 비슷한 변형 문제, 가장 중요한 단서만 알려 주는 힌트 한 번, 답을 입력하면 정답 여부와 풀이

먼저 떠올린다틀린 것을 다시 본다힌트는 한 단계씩

AI가 틀린 순간 비슷한 문제 대신 훨씬 쉬운 새 문제를 냈습니다. "형식은 유지하고 숫자만 바꿔 줘"라고 요청해 해결했습니다. 수식이 $f(x)$ 같은 컴퓨터 표기로 나와서 수학 수식으로 바꿨습니다.

제안: "이미지 첨부가 안 되고 카메라만 쓸 수 있어 아쉬웠다" → 만든 모둠의 답: "카메라 촬영을 뜻했는데, 그렇게 전달될 수도 있겠네요. 좋은 피드백 감사합니다."

모둠 G

현대사 암기 마스터

출발한 불편 한국사 사건의 순서가 잘 외워지지 않습니다.

기능 사건 암기 카드('몰랐다'를 누르면 5장 안에 다시), 사건을 끌어다 놓는 시간순 배열 퀴즈, 설명과 연도를 보고 사건 이름 쓰기

먼저 떠올린다틀린 것을 다시 본다힌트는 한 단계씩

AI가 틀린 순간 카드를 끌어 옮길 수 없었고, 단답형을 틀리면 다시 풀 수 없거나 정답이 바로 보였습니다. 틀리면 연도만 힌트로 주고 정답 보기 버튼은 따로 두게 했습니다. "8.15"처럼 점을 써도 정답으로 인정하게 했습니다.

AI 사용 규칙 "나는 AI를 궁금한 게 생겼을 때 쓰고, 검색 플랫폼에 검색해서 맞는지 확인한다."

"나에게 딱 필요했던 앱… 한국사 100점 감사합니다"

모둠 H

한국사 스터디

출발한 불편 한국사 순서가 헷갈리고, 틀린 문제는 다시 보지 않게 됩니다.

기능 연도 범위를 넣으면 사건을 순서대로 나열, 주요 단어 빈칸 퀴즈, 틀린 문제만 모아 다시 풀기

틀린 것을 다시 본다

AI가 틀린 순간 틀리자마자 오답노트로 넘어가서 힌트를 먼저 보여 주도록 고쳤습니다. 오답노트에서 다시 풀 수 없던 것, 다시 틀려도 정답이 나오지 않던 것도 고쳤습니다. 연도별 학습에서 답이 화면 아래에 보이던 것도 가렸습니다.

"오답이 오답노트로 모이는 게 좋은 것 같아요." · 제안: '정답 입력' 칸이 짧아 글자가 잘림

돌아보며

기록을 다시 읽으며 눈에 띈 점은 네 가지입니다.

  • 가장 많이 들어간 원칙은 '틀린 것을 다시 본다'였습니다. 거의 모든 앱이 오답 다시 풀기, 변형 문제, 간격 복습 가운데 하나를 넣었습니다.
  • AI는 앱을 만들 때도 그럴듯하게 틀렸습니다. 고치면 앞서 고친 기능이 사라지거나(A), 같은 요청을 반복해도 고쳐지지 않거나(E), 일부만 고쳐지거나(C·D), 수식이 컴퓨터 표기로 나왔습니다(C·F). 학생들은 한 번에 하나씩, 말을 바꿔 가며 다시 요청했습니다.
  • 내용을 누가 만드는지는 모둠마다 달랐습니다. E·G 모둠은 내용을 직접 넣는 앱을 만들었고, A·C·F 모둠은 AI가 변형 문제를 만들고, H 모둠은 연도 범위를 넣으면 AI가 사건을 나열하는 앱을 만들었습니다. E 모둠의 출발점이 "AI가 틀린 내용을 말했다"였던 것을 생각하면, AI가 만든 문제와 사건 목록은 교과서로 한 번 더 확인해야 합니다.
  • B 모둠은 '힌트는 한 단계씩'을 원칙으로 정했지만, 만드는 과정에서 앱이 문제를 직접 풀도록 바꿨습니다. 편리함과 스스로 떠올리기 사이의 고민이 그대로 드러난 장면입니다.

제 생각

1차에서 학생들은 AI를 틀리게 만드는 데 강사보다 나았습니다. 2차에서는 그 눈이 앱을 만드는 과정에도 이어졌습니다. "저장되지 않은 단어는 모른다고 말해야 한다"는 D 모둠의 테스트나, 같은 요청이 통하지 않자 방식을 바꾼 E 모둠의 수정은 1차에서 본 실패를 자기 앱에 적용한 결과로 읽힙니다.

아쉬운 점도 있습니다. 서로의 앱을 공격해 보는 교차 테스트 칸은 모든 모둠이 비워 두었고, AI 사용 규칙 한 줄은 한 모둠만 썼습니다. 만드는 시간에 몰입한 만큼 마무리 시간이 모자랐습니다. 다음에는 '내용은 내가 넣는다'를 기획서의 테스트 항목으로 넣고, 교차 테스트 시간을 따로 떼어 두려고 합니다.

남는 질문은 이렇습니다.

  • AI가 문제를 만들어 주는 앱은 학생의 생각을 돕는 앱일까요, 대신하는 앱일까요.
  • 편리함을 원하는 학생에게 '스스로 떠올리기'를 앱 안에서 어떻게 지켜 줄 수 있을까요.
