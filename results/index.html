1차 · 학생들이 찾은 AI의 실패

Gemini는 강사가 준비한 '실패할 질문'은 대부분 맞혔습니다. 실패를 끌어낸 것은 학생들이 직접 만든 질문이었습니다.

유형모둠질문 → AI의 답진짜 정답
① 지어낸다라니체의 정신 3단계를 칼 세이건의 (없는) 책 내용처럼 꾸며 6번째 소제목을 물음 → "위대한 인간이 되기 위한 조건"없는 책

모둠 A

모기 (모의고사 지문 분석기)

출발한 불편 모의고사 오답에서 같은 내용을 자꾸 틀린다. 영어 시험 범위가 넓어 기억하기 힘들다.

기능 지문 도식화 · 지문 내용 퀴즈 · 시험에 나올 문법 요소를 형광펜으로 표시

틀린 퀴즈는 변형해서 다시한 문장씩 해석

AI가 틀린 순간 수정을 요청하면 이전에 고친 내용이 사라졌다. 되돌려 달라는 요청도 통하지 않아 처음부터 다시 만들었다. 변형 문제가 한 번만 나오거나 다음 문제로 넘어가지 않는 문제도 하나씩 고쳤다.

"형광펜으로 중요한 부분을 표시해서 보기 편함" · "등록한 문제를 다른 형태로 바꿔 풀 수 있는 기능이 좋았다" · 제안: 글자를 더 크게

모둠 B

클락

출발한 불편 공부하다 모르는 단어나 내용을 하나하나 찾아보느라 시간이 낭비된다.

기능 개념 설명 · 예문과 관련 기출 · 유의어/반의어 · 1일·1주·2주·1달 뒤 복습

힌트는 키워드부터 한 단계씩

AI가 틀린 순간 문제를 풀어 달라고 했더니 앱이 사용자에게 풀이를 요구했다. "앱이 직접 찾아서 알려 줘야 한다"고 고쳐 앱이 문제를 풀게 했다.

"모든 과목의 개념을 공부할 수 있고, 카메라로 필요한 부분을 직접 등록할 수 있어 편리하다. 카드도 섞을 수 있다."

모둠 C

Øpick! (오픽)

출발한 불편 틀린 문제를 다시 풀어 보고 확인하기가 번거롭다.

기능 문제집을 찍으면 문제·보기·해설을 잘라 입력 · 오답 원인 태그(계산 실수, 개념 미숙, 문제 오독) · 자주 틀리는 유형 통계

틀린 것을 다시 본다먼저 떠올린다단계별 힌트

AI가 틀린 순간 객관식 답을 고를 수 없었다 → 고쳤더니 다른 곳이 망가져 다시 고침. 수식이 어색하게 나와 수능 스타일 수식으로(일부 해결), 오답 제목에 수식이 깨져 "범위·종류·번호"로 바꿈(해결). 단계별 힌트는 끝까지 구현되지 않았다.

"오답을 하였을 때 틀린 것을 바로 복습하게 해 주는 것이 정말 좋았어요." · 제안: 예시 문제가 더 많았으면

모둠 D

클딱 (영단어 사전)

출발한 불편 영어 공부 중 모르는 단어를 휴대폰으로 찾느라 시간이 걸린다.

기능 카메라 즉시 번역 · 원터치 '1초 단어장' · 검색한 단어 분류와 맞춤 복습

모르면 모른다고 대답한다

테스트 중 하나 "앱에 저장되어 있지 않은 단어가 나오면 확실히 모른다고 말해야 한다." — 1차에서 본 '지어낸다'를 앱 테스트로 옮겼다.

AI가 틀린 순간 정한 앱 이름 대신 "영단어사전"이라고 지었다. 아이콘 수정 요청은 한 번에 반영되지 않았다. 단어를 미리 넣어 두도록 바꾸자 일부 단어만 바로 나오고 나머지는 '등록 요청'이 떴다.

모둠 E

Matter matterS

출발한 불편 AI가 18족 원소의 원자가 전자 수를 틀리게 설명해 선생님께 다시 확인했다. 사회 서술형 문제를 부탁하니 범위 밖 내용과 처음 보는 사상가가 나왔다.

기능 개념과 설명을 직접 입력 · 설명의 일부를 보여 주고 개념을 쓰게 하는 문제 · 30초 제한

먼저 떠올린다틀린 것을 다시 본다

AI가 틀린 순간 개념 삭제 버튼이 작동하지 않았다. 같은 요청을 두 번 해도 그대로여서, 방식을 바꿔 "한 번 더 묻고 삭제"하도록 요청하자 해결됐다. 퀴즈 중단·전체 삭제도 같은 방식으로 고쳤다.

"개념 관리와 퀴즈 풀이를 같이 하면서 사탐 개념을 배우기 좋을 것 같아요." · 제안: 과탐도

모둠 F

풀림

출발한 불편 틀린 문제와 비슷한 변형 문제를 풀어 보고 싶다.

기능 틀린 문제를 찍으면 형식이 비슷한 변형 문제 · 힌트는 한 번(가장 중요한 단서만) · 답을 입력하면 정답 여부와 풀이

먼저 떠올린다틀린 것을 다시 본다힌트는 한 단계씩

AI가 틀린 순간 비슷한 문제 대신 훨씬 쉬운 새 문제를 냈다 → "형식은 유지하고 숫자만 바꿔 줘"로 해결. 수식이 $f(x)$ 같은 컴퓨터 표기로 나와 수학 수식으로 바꿨다.

제안: "이미지 첨부가 안 되고 카메라만 쓸 수 있어 아쉬웠다" → 주인 모둠: "카메라 촬영을 뜻했는데, 그렇게 전달될 수도 있겠네요. 좋은 피드백 감사합니다!"

모둠 G

현대사 암기 마스터

출발한 불편 한국사 사건의 순서가 잘 외워지지 않는다.

기능 사건 암기 카드('몰랐다'는 5장 안에 다시) · 사건을 끌어다 놓는 시간순 배열 퀴즈 · 설명과 연도를 보고 사건 이름 쓰기

먼저 떠올린다틀린 것을 다시 본다힌트는 한 단계씩

AI가 틀린 순간 카드를 끌어 옮길 수 없었고, 단답형을 틀리면 다시 풀 수 없거나 정답이 바로 보였다 → 틀리면 연도를 힌트로만 주고 정답 보기 버튼은 따로. "8.15"처럼 점을 써도 정답으로 인정하게 했다.

우리의 AI 사용 규칙 "나는 AI를 궁금한 게 생겼을 때 쓰고, 검색 플랫폼에 검색해서 맞는지 확인한다."

"나에게 딱 필요했던 앱… 한국사 100점 감사합니다"

모둠 H

한국사 스터디

출발한 불편 한국사 순서가 헷갈리고, 틀린 문제는 다시 보지 않게 된다.

기능 연도 범위를 넣으면 사건을 순서대로 · 주요 단어 빈칸 퀴즈 · 틀린 문제만 모아 다시 풀기

틀린 것을 다시 본다

AI가 틀린 순간 틀리자마자 오답노트로 넘어가 버림 → 힌트 먼저. 오답노트에서 다시 풀 수 없음 → 해결. 다시 틀려도 정답이 안 나옴 → 해결. 연도별 학습에서 답이 화면 아래에 보이던 것도 고쳤다.

"오답이 오답노트로 모이는 게 좋은 것 같아요!" · 제안: '정답 입력' 칸이 짧아 글자가 잘림

수업을 마치고 본 것

  • '틀린 것을 다시 본다'가 가장 많이 들어간 원칙이었습니다. 거의 모든 앱이 오답 다시 풀기, 변형 문제, 간격 복습 중 하나를 넣었습니다.
  • AI는 앱에서도 그럴듯하게 틀렸습니다. 고치면 앞서 고친 기능이 사라지거나(A), 같은 요청을 반복해도 안 고쳐지거나(E), 일부만 고쳐지거나(C·D), 수식이 컴퓨터 표기로 나왔습니다(C·F). 모둠들은 요청을 한 번에 하나씩, 다른 말로 바꿔 가며 고쳤습니다.
  • 내용은 누가 만드나? E·G 모둠은 내용을 직접 넣는 앱을, A·C·F 모둠은 AI가 변형 문제를 만드는 앱을, H 모둠은 연도 범위를 넣으면 AI가 사건을 나열하는 앱을 만들었습니다. E 모둠의 출발점이 바로 "AI가 틀린 내용을 말했다"였던 만큼, AI가 만든 문제와 사건 목록은 교과서로 한 번 더 확인해야 합니다.
  • 생각을 맡길까, 생각하게 할까. B 모둠은 '힌트는 한 단계씩'을 원칙으로 정했지만, 만드는 중에는 앱이 문제를 직접 풀도록 바꿨습니다. 편리함과 '스스로 떠올리기' 사이의 고민이 그대로 드러난 장면이라 다음 수업의 토론 거리로 남깁니다.
AI를 틀리게 만들 줄 아는 사람이 AI로 제대로 만들 수도 있습니다. — 2차 정리 슬라이드에서
